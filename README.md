# Drew Academy Bot 🤖

Telegram text utility for sorting lists alphabetically and numerically.

**Bot:** @Drew_AcademyBot

## Features

- 🔤 Sort text A–Z
- 🔢 Sort numbers 1–9
- Accepts one item per line or comma-separated items
- Friendly welcome message and built-in guide
- Uses aiogram 3.x

## Setup

1. Create a bot with Telegram BotFather and copy the token.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Set the environment variable:

```bash
BOT_TOKEN=your_token_here
```

4. Run:

```bash
python bot.py
```

Never commit your real bot token to GitHub.
